# IXCSoft Mapa v0.8.1

## Deploy automatizado no Debian

Esta versão padroniza a atualização da aplicação com o comando global `apply`.

### O comando executa

- verificação do Git e Docker Compose;
- proteção contra alterações locais;
- atualização segura da branch `main`;
- reconstrução e inicialização dos containers;
- espera pelo health check da aplicação;
- verificação dos serviços `web`, `worker` e `beat`;
- relatório final com versão, commits e duração;
- exibição dos logs recentes quando ocorre uma falha.

### Primeira instalação

Dentro de `/opt/ixcsoft-mapa`, execute:

```bash
chmod +x scripts/install_apply_command.sh
./scripts/install_apply_command.sh
```

Nas próximas atualizações, use somente:

```bash
apply
```
