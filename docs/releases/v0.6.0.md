# IXCSoft Mapa v0.6.0

Release de infraestrutura e primeiro deploy de produção.

## Adicionado

- Dockerfile preparado para produção
- Entrypoint com modos `web`, `worker`, `beat`, `migrate` e `collectstatic`
- Gunicorn configurável por variáveis de ambiente
- Healthchecks separados de liveness e readiness
- Configuração opcional de Nginx
- `.dockerignore`
- Compose com PostGIS, Redis, web, Celery Worker, Celery Beat e Nginx
- Documentação de deploy no EasyPanel
- Variáveis de segurança para domínio, CSRF e proxy HTTPS

## Corrigido

- Worker e Beat não executam mais migrations nem coleta de estáticos
- Versão da API e do healthcheck agora usa `APP_VERSION`
- `ALLOWED_HOSTS` não usa mais `*` como padrão

## Como atualizar

1. Atualize a branch `main`.
2. Configure as variáveis do `.env.example` no EasyPanel.
3. Faça o deploy do serviço web.
4. Verifique `/api/health/ready/`.
5. Suba Worker e Beat usando a mesma imagem.
