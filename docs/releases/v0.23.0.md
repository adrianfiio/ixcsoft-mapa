# AFService Map v0.23.0

Esta versão corrige a interpretação dos dados do IXCSoft e amplia o mapa para redes ópticas e wireless.

## Destaques

- Registros IXC com nome CDO passam a aparecer como CEO/caixa de emenda.
- A conversão preserva a caixa original e seus vínculos; não é necessário limpar a empresa.
- O mapa abre em modo de visualização, com o painel recolhido.
- O popup do cliente mostra PPPoE, CTO, porta, ONU e serial quando esses dados estão vinculados.
- O editor passa a oferecer Rack e Torre, com cadastro de equipamentos internos.

## Atualização

No servidor, execute:

```bash
apply
```

As migrações corrigem automaticamente os CDOs IXC já importados.
