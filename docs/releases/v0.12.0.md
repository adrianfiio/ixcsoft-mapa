# AFService Map v0.12.0

Esta versão conecta o desenho geográfico ao caminho óptico configurado no unifilar.

## Alterações

- O sinal parte da OLT, mas só continua depois de uma CEO quando existe fusão ou ligação de splitter.
- Cabos que chegam à CEO aparecem à esquerda; cabos que saem aparecem à direita.
- Um cabo pode ser desenhado clicando no equipamento de origem, marcando o trajeto e clicando no equipamento de destino.
- Origem e destino são preenchidos automaticamente antes de salvar.
- A seleção do modelo define a quantidade de fibras automaticamente.
- As opções de modelo foram simplificadas por quantidade de fibras.
- O nome sugerido segue o padrão `CABO ORIGEM → DESTINO · NF`.
- Uma camada permite mostrar ou ocultar nomes de cabos e equipamentos.

## Atualização

```bash
apply
```

Após atualizar, recarregue o navegador com `Ctrl+F5`.
