# Release 0.5.1

Esta é uma atualização de organização da documentação.

## Principais mudanças

- O `README.md` agora apresenta o sistema de forma permanente.
- O histórico das versões foi movido para `CHANGELOG.md`.
- Foi criado um template padrão para novas releases.
- As próximas atualizações não substituirão o README por notas de versão.

## Atualização

Não existem alterações de banco de dados nesta versão.

Basta substituir os arquivos do projeto ou atualizar o repositório.
