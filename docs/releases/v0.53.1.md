# AFService Map v0.53.1

Backup/ponto de rollback desta rodada: tag `v0.53.0` no GitHub.

Corrige o editor de dashboard (arrastar não funcionava) e generaliza o
nome do painel de sincronização, que estava amarrado ao nome do IXCSoft.

## Principais mudanças

### Corrigido

- **Arrastar não funcionava no editor de dashboard**: a causa era um
  conflito entre CSS e JS — cada widget tinha `order: N` fixado direto no
  `style`, pra funcionar sem depender de JavaScript na visão normal da
  empresa. Só que o SortableJS reordena *movendo elementos de verdade* no
  DOM ao arrastar; com o `order` fixo por CSS, o navegador continuava
  desenhando cada item na posição antiga, então parecia que nada
  acontecia ao soltar. Agora a ordem fica guardada numa custom property
  (`--order`) e só vira `order` de CSS de verdade **fora** do modo de
  edição; dentro do editor, o JavaScript aplica essa ordem reorganizando o
  DOM de verdade antes de ligar o arrastar — a partir daí, arrastar e
  soltar funciona normalmente.
  - Se por algum motivo o SortableJS não carregar (rede, CDN fora do ar),
    o editor agora mostra um aviso e mantém mostrar/esconder e salvar
    funcionando — antes, a tela inteira travava silenciosamente.
- **Painel "Sincronização IXCSoft" → "Sincronização com ERP"**: o texto
  fixo assumia que o único ERP possível era o IXCSoft. Agora mostra o
  nome do provedor configurado dinamicamente (hoje é IXCSoft, porque é o
  que já está integrado, mas o rótulo não trava mais nisso).

## Atualização

Execute `apply` no servidor. Sem migration nesta versão.
