# AFService Map v0.28.1

Reorganização do painel "Minha administração", sem mudanças de modelo de dados.

## Principais mudanças

- "Minha administração" ganhou item próprio no menu lateral;
- novo bloco **Configurações da empresa** no topo do painel, com atalhos
  diretos para Dados da empresa, Minha equipe, Integração ERP (quando a
  empresa usa ERP) e Central de alertas;
- a tela de dados da empresa passa a se chamar "Dados da empresa" (em vez de
  repetir o texto de boas-vindas) quando acessada depois do primeiro acesso;
- removidas as seções duplicadas de "Integração ERP" e o aviso genérico de
  "Alertas" que existiam dentro do painel — ambas já têm página própria.

## Deixado para depois, de propósito

SMTP e envio de e-mail de alertas ficam para uma próxima etapa: hoje nada no
sistema envia e-mail (nem recuperação de senha, nem o motor de alertas, que
ainda não existe), então configurar SMTP agora não teria efeito visível.

## Atualização

Execute `apply` no servidor. Não há migração de banco nesta versão.
