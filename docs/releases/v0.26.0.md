# AFService Map v0.26.0

Esta versão corrige o fluxo de acesso das empresas sem ERP e torna o cadastro da
estrutura técnica mais previsível.

## Principais mudanças

- usuários manuais EDIT conseguem concluir o primeiro acesso e criar seus projetos;
- usuários manuais não recebem menus ou páginas de integração ERP;
- logout retorna ao login normal da plataforma;
- OLT manual é criada sem exigir IP, modelo ou community;
- OLT por SNMP exige IP e aceita community criptografada;
- placas usam automaticamente o próximo slot disponível;
- DIO não solicita IP de gerência;
- ligações internas ficam recolhidas até serem necessárias;
- equipamentos podem ser selecionados e excluídos em lote na página atual;
- perfis VIEW não recebem ações de alteração.

## Atualização

Execute `apply` no servidor. A migração promove somente contas manuais incompletas
de VIEW para EDIT e mantém o isolamento dos dados por empresa.
