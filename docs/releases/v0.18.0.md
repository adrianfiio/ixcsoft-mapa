# AFService Map v0.18.0

Esta versão inicia o fluxo de implantação por empresa.

- O primeiro acesso EDIT direciona à vinculação do ERP.
- A empresa escolhe quais dados importar do IXCSoft.
- Clientes, contratos, PPPoE, projetos e CTOs são isolados por empresa.
- Contratos ativos são vinculados aos clientes e aos logins correspondentes.
- CPDs/POPs podem ser posicionados por coordenadas, GPS ou pesquisa no mapa.
- Os atalhos da plataforma não expõem o Django Admin aos usuários das empresas.

Depois de atualizar, execute `apply`; as novas migrações são aplicadas automaticamente.
