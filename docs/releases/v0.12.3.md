# AFService Map v0.12.3

Esta versão melhora a inspeção de cabos grandes e a leitura do mapa.

## Alterações

- Cada cabo possui um botão para expandir ou recolher todas as fibras.
- A expansão funciona com cabos de 24, 72 fibras ou capacidades maiores e fica salva por caixa.
- O resumo duplicado de fusões foi removido; as ligações continuam editáveis diretamente pelas linhas.
- A camada “Sem estado” foi retirada do menu.
- O mapa mostra apenas os controles de clientes PPPoE online e offline.
- Dois controles inferiores permitem agrupar ou separar PPPoE e equipamentos.
- O satélite sem API foi definido como visualização inicial, mantendo o mapa de ruas como alternativa.

## Atualização

```bash
apply
```

Após atualizar, recarregue o navegador com `Ctrl+F5`.
