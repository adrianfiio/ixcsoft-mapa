# AFService Map v0.50.0

Backup/ponto de rollback desta rodada: tag `v0.49.0` no GitHub.

Adiciona a opção de excluir um projeto de rede inteiro direto pelo painel
de administração da empresa, com aviso claro do que será perdido antes de
confirmar.

## Principais mudanças

### Adicionado

- **"Excluir projeto" em Minha administração** (`/painel/`): a seção
  "Projetos" (que já listava os projetos da empresa) agora tem um link
  vermelho "Excluir projeto" ao lado de cada um — visível só para quem tem
  permissão de edição em pelo menos uma empresa.
- **Tela de confirmação** antes de apagar qualquer coisa: mostra quantos
  elementos (postes, CTOs, CEOs/CDOs, racks, DIOs, OLTs, splitters,
  fusões...), cabos, rotas, lotes de importação KMZ e POP existem no
  projeto. Só executa a exclusão se o código exato do projeto for digitado
  no campo de confirmação — sem isso, nada é apagado.
- A exclusão remove **o projeto inteiro**, incluindo o próprio registro do
  projeto (diferente do comando `wipe_network_project`, que zera a
  estrutura mas mantém o projeto para reuso). A lógica de apagar foi
  centralizada em `apps/network_map/services.py`
  (`project_structure_counts` e `wipe_project_structure`), reaproveitada
  tanto pela tela nova quanto pelo comando de manutenção — antes essa
  lógica só existia duplicada dentro do comando.
- **Correção de acabamento**: o layout usado pela maioria das páginas do
  site (fora do editor de mapa) nunca mostrava as mensagens de sucesso/erro
  que o Django já gerava internamente — elas existiam, mas não apareciam em
  lugar nenhum da tela. Agora aparecem no topo do conteúdo, com cor
  diferente para sucesso, erro, aviso e informação. Isso também é o que faz
  o aviso de "código de confirmação errado" aparecer na tela nova.

## Atualização

Execute `apply` no servidor. Sem migration nesta versão.
