# AFService Map v0.33.0

O rack ganha o mesmo tipo de diagrama de Fusões que a CTO/CEO já tinha,
substituindo a lista rápida introduzida na v0.32.1.

## Principais mudanças

- Novo botão **"Fusões"** no popup do rack no mapa (junto de Editar,
  Equipamentos, Excluir), igual ao que já existe para CTO/CEO.
- Ao clicar, abre um diagrama visual dedicado: **cabos ligados ao rack**
  (com suas fibras coloridas, uma por uma) de um lado, **DIOs cadastrados**
  do outro. Clique numa fibra e depois numa porta do DIO para criar a
  fusão; clique numa fibra ou porta já ligada para desfazer. Uma linha
  conectando os dois pontos mostra visualmente cada fusão feita.
- A fusão passa a ser registrada no nível da fibra específica do cabo, não
  mais só do cabo inteiro — mesmo padrão já usado na fusão da CTO/CEO.

## O que saiu

A lista de fusão rápida (portas do DIO à esquerda, cabos à direita) que
tinha sido adicionada dentro do modal "Estrutura" na v0.32.1 foi removida
— o lugar certo para isso é o novo diagrama, reaproveitando o mesmo padrão
visual da CTO/CEO. O formulário de ligação PON da OLT ↔ porta do DIO,
dentro de "Estrutura", continua exatamente como estava.

## Atualização

Execute `apply` no servidor. A migração adiciona um campo novo — não afeta
fusões já existentes.
