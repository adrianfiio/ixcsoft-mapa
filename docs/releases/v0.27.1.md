# AFService Map v0.27.1

Ajustes de navegação e de operação do servidor, sem mudanças de modelo de dados.

## Principais mudanças

- login abre direto a **Visão geral**, em vez do painel técnico;
- topo da tela mostra só o nome do usuário e "Sair" — sem o link "API" e sem
  o círculo com iniciais;
- o gate de primeiro acesso (tipo de empresa, modo ERP/manual e configuração
  pendente do IXCSoft) agora vale também para a Visão geral e o mapa, não só
  para o painel técnico;
- documentado no README como configurar um Personal Access Token (ou SSH) no
  servidor Debian para o `apply` parar de pedir usuário e senha a cada
  atualização.

## Atualização

Execute `apply` no servidor. Não há migração de banco nesta versão. Se o
`apply` estiver pedindo usuário e senha do GitHub a cada execução, veja a
seção "Evitar usuário e senha em toda atualização" no README.
