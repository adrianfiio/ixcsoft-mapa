# AFService Map v0.14.2

Esta versão melhora os formulários do mapa, a localização dos ativos e toda a navegação administrativa.

## Destaques

- CTO, CEO, reservas e splitters usam formulários internos modernos, sem `prompt()` do navegador.
- O admin ganhou atalhos para mapa, projetos, CPDs, OLTs e DIOs.
- Listas e formulários administrativos ficaram mais claros e organizados.
- Mapas GIS administrativos abrem na região de Imbaú.
- CPD e DIO aceitam busca de endereço, GPS e coordenadas.
- DIO pode herdar a localização do CPD.
- CPD pode herdar uma localização já existente no projeto.

## Atualização

Execute no servidor como usuário normal:

```bash
apply
```

Depois recarregue o navegador com `Ctrl+F5`.
