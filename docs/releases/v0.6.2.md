# IXCSoft Mapa v0.6.2

Release corretiva de implantação no EasyPanel.

## Mudanças

- `docker-compose.yml` dedicado à produção no EasyPanel;
- remoção de `ports` nos serviços de produção;
- remoção de PostgreSQL, Redis e Nginx internos do Compose de produção;
- serviços `web`, `worker` e `beat` separados;
- novo `docker-compose.local.yml` para desenvolvimento local completo;
- `.env.example` atualizado;
- documentação de domínio e implantação no EasyPanel;
- versão padrão da API atualizada para `0.6.2`.

## Domínio

O proxy do EasyPanel deve apontar para o serviço `web`, porta interna `8000`.
