## Pendente (fora deste fix)

`requirements.txt` também foi editado direto no servidor (`nano
requirements.txt`, provavelmente pra adicionar `influxdb-client`). Esse
é um arquivo **rastreado** pelo Git — `.gitignore` não tem efeito nele.
Se o conteúdo desse arquivo não for resolvido antes do próximo `apply`,
ele vai continuar cancelando a atualização (`requirements.txt`
apareceria como modificado, não como `??`). Isso precisa ser tratado à
parte, com o diff real do arquivo em mãos.
