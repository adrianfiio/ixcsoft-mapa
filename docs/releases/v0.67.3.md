# AFService Map v0.67.3 — Hotfix de performance no mapa

Backup/ponto de rollback desta rodada: tag `v0.67.2`. Hotfix da área do
mapa preparado pelo ChatGPT ("v0.10.2" na numeração dele), aplicado aqui
via `apply_v0102.py` (validado antes com `--dry-run`).

Substitui só dois arquivos: `static/js/map-optical-editor-v2.js` e
`static/js/map-optical-editor-v3.js`. Sem banco, migration, dashboard ou
configuração de empresa envolvidos.

## Corrigido

- **Performance do Editor Óptico v2/v3**: um único `MutationObserver`
  observava o `document` inteiro e reprocessava tudo (ícones, popups,
  filtro de rota, lista de equipamentos, fusões, diagrama interno) a cada
  mudança no DOM — inclusive mudanças produzidas pelo próprio editor de
  linhas manual, causando reprocessamento em cascata. Trocado por três
  observadores escopados (mapa, tela de fusões, diálogo de
  rack/torre), cada um só reagindo a mutações relevantes (marcador novo,
  popup, filtro de rota) e ignorando as próprias alças de edição de linha
  (`.manual-route-handle-v2`, `.container-route-handles-v3`), com
  debounce (~30-50ms) pra agrupar rajadas de mudança numa só passada.
  Marcadores e botões já processados ganham uma marca
  (`.network-marker-v3`, `data-optical-v2-renamed`) pra nunca ser
  retrabalhados.

## Verificação feita nesta rodada

- `--dry-run` do hotfix rodado antes da aplicação real, sem erro.
- Aplicação real: só os dois arquivos previstos foram alterados.
- Sintaxe de `map-optical-editor-v2.js` e `map-optical-editor-v3.js`
  verificada com esprima.
- Leitura do diff completo: mudança é só de escopo/observação de DOM
  (client-side), sem endpoint novo nem alteração de payload — nada de
  segurança ou isolamento entre empresas envolvido nesta rodada.

**O teste com volume real de elementos (projeto grande, muitos
marcadores) precisa ser feito no servidor — é justamente o cenário que
esse hotfix teoricamente melhora.**

## Atualização

Execute `apply` no servidor. Sem migration nesta versão. Depois de
atualizar, um `Ctrl+F5` no navegador garante que o JavaScript novo seja
carregado (evita cache do arquivo antigo).

manualmente e observar se a interface fica mais responsiva (sem travar

estrutura de rack/torre várias vezes seguidas e conferir que continua
tudo funcionando normalmente (ícones, popups, filtro de rota).
