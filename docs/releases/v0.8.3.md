# IXCSoft Mapa v0.8.3

## Validação completa da interface

Esta versão corrige definitivamente o dashboard sem estilo observado atrás do
Nginx legado.

### Corrigido

- CSS principal entregue pela rota `/assets/app.css`;
- compatibilidade com o Nginx que intercepta `/static/`;
- validação do CSS incluída no comando `apply`;
- prefixo duplicado na versão da interface removido.

O deploy agora só apresenta `SUCESSO` depois de confirmar o backend, o CSS e os
três serviços da aplicação.
