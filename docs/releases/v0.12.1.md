# AFService Map v0.12.1

Esta versão unifica a configuração óptica de CEOs e CTOs.

## Alterações

- A CTO agora abre o mesmo editor unifilar visual utilizado pela CEO.
- É possível ligar uma fibra do cabo de entrada diretamente à fibra do cabo seguinte.
- É possível alimentar o splitter e ligar suas saídas às fibras de outros cabos.
- O splitter aparece na vertical: uma entrada na parte superior e as saídas abaixo.
- CTOs existentes recebem automaticamente uma bandeja e preservam a entrada já configurada.
- A seta luminosa gira conforme o ângulo do cabo e aponta corretamente para o destino.

## Atualização

```bash
apply
```
