# AFService Map v0.14.1

Esta versão corrige a gestão de infraestrutura dos postes e padroniza os ícones do editor.

## Destaques

- O poste mostra somente cabos cuja geometria passa a até 8 metros dele.
- Somente CTOs e CEOs efetivamente instaladas aparecem na infraestrutura do poste.
- É possível instalar CTO ou CEO diretamente pelo poste.
- A reserva técnica só pode ser adicionada quando há um cabo passando no local.
- O marcador `P` foi substituído por um desenho vetorial de poste.
- Os botões do menu e os atalhos recolhidos receberam ícones consistentes.

## Atualização

No servidor, execute como usuário normal:

```bash
apply
```

Depois, recarregue o navegador com `Ctrl+F5`.
