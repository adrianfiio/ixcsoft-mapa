# AFService Map v0.21.0

Esta versão separa corretamente cabos e caixas importados do IXCSoft e organiza
o editor em modos de operação mais claros.

## Importação IXCSoft

- Registros de `df_elemento` identificados como cabo entram como `FiberCable`.
- A quantidade de fibras é reconhecida pelo cadastro quando disponível e pelo
  nome, incluindo formatos como `6FO`, `12 F.O` e `24 fibras`.
- Cabos sem geometria ficam no inventário como “aguardando traçado”.
- O menu do mapa permite selecionar um desses cabos e desenhar sua origem,
  caminho e destino sem criar um cadastro duplicado.
- CDO e caixa de atendimento são tratados como CTO.
- CEO, CF e caixa de emenda são tratadas como caixa de emenda.
- Registros equivalentes de `rad_caixa_ftth` e `df_elemento` são consolidados.

## Editor do mapa

A nova barra superior oferece os modos:

- Visualizar
- Editar
- Desenhar cabo
- Pesquisar

## Limitação conhecida da fonte

Os exemplos de API fornecidos para `df_elemento` contêm identificação,
descrição e tipo, mas não contêm geometria, distância, origem ou destino do
cabo. O AFService Map não cria um caminho fictício: o traçado deve ser
desenhado pelo operador, importado por KML/KMZ ou recebido futuramente de um
endpoint do IXCSoft que exponha essas informações.
