# AFService Map v0.52.0

Backup/ponto de rollback desta rodada: tag `v0.51.0` no GitHub.

Primeira entrega da ferramenta de "construir o site" que você pediu: um
editor visual do dashboard, por empresa, só pra você (superusuário) — as
empresas continuam sem nenhum controle de edição, só veem o resultado.

## Contexto: por que esse escopo

Pesquisei o projeto inteiro antes de construir (sem CMS instalado, sem
build JS, sem campo de marca na empresa, sem nenhum "ver como cliente X"
hoje). A maioria das páginas do site (alertas, e-mail, equipe) é gerada
quase 100% por dados — não têm blocos fixos de conteúdo pra reorganizar.
O dashboard é a exceção: uma grade fixa de cartões e painéis, unidade
natural pra "widget" que faz sentido esconder/reordenar. Por isso a
primeira entrega foca nele — não é um CMS genérico de páginas livres (isso
seria uma obra bem maior, e um passo separado se você quiser mais adiante).

## Principais mudanças

### Adicionado

- **Editor de dashboards** (`/painel/dashboards/`, só superusuário):
  lista as empresas; escolher uma abre o dashboard dela em modo de edição.
  - **Arrastar e soltar**: cada cartão/painel tem uma alça (⋮⋮) — arraste
    pra reordenar. Cartões de métrica reordenam entre si; painéis
    reordenam dentro da própria coluna (esquerda/direita).
  - **Mostrar/esconder**: cada widget tem uma caixinha "Visível" — desmarque
    pra esconder da empresa (fica esmaecido só na tela de edição, pra você
    ainda conseguir reordenar e reativar depois).
  - **Mensagem no topo**: campo de texto livre (até 280 caracteres) que
    aparece como um aviso destacado no topo do dashboard daquela empresa —
    útil pra avisos de manutenção, boas-vindas, etc.
  - Botão "Salvar layout" grava tudo de uma vez. Sem nada salvo ainda, o
    dashboard da empresa continua exatamente como sempre foi.
- Link novo "Editor de dashboards →" em "Minha administração", ao lado do
  "Painel técnico completo" que já existia pra superusuário.

## O que fica pra depois (se você quiser seguir)

- **Whitelabel de marca** (logo/cor/nome por empresa) — não entrou nessa
  entrega, é um projeto separado e mais simples.
- **Editor de páginas livres** (adicionar blocos de texto/imagem
  arbitrários, não só reordenar o que já existe) — exigiria adotar um CMS
  de verdade (ex.: Wagtail) ou um editor de blocos construído do zero;
  avisei que é uma obra bem maior antes de começar essa entrega.
- Reordenar só funciona dentro da mesma coluna/grade — não dá pra arrastar
  um painel da coluna esquerda pra direita ainda.
