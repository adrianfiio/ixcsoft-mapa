# AFService Map v0.41.0

Backup/ponto de rollback desta rodada: tag `v0.40.0` no GitHub.

Corrige o formulário de cabo novo, dá zoom e organiza o diagrama de
estrutura, e melhora a identificação da OLT no sinal de luz — mais uma
pergunta pra fechar de vez esse bug.

## Principais mudanças

### Corrigido

- **Formulário de cabo novo**: o nome não vem mais pré-preenchido com
  "12F" antes de você escolher o modelo do cabo — a quantidade de fibras
  só aparece no nome depois que o modelo é escolhido. "Modelo / quantidade
  de fibras" agora é obrigatório para salvar, e o campo "Quantidade de
  fibras" passou a ser só uma vitrine do que o modelo escolhido define —
  não dá mais para digitar um número solto ali.

### Adicionado

- **Diagrama da estrutura** (tela de Equipamentos do rack/torre) ganhou
  controle de zoom (−, %, +, Ajustar), mais espaçamento entre os botões
  Editar/Excluir de cada equipamento, e ajustes de layout para telas
  pequenas (celular).
- A lista "OLT de origem" do sinal de luz agora deixa claro no próprio
  texto se a OLT é um elemento avulso no mapa ("(elemento avulso)") ou uma
  OLT dentro de um rack ("· rack NOME"), pra facilitar escolher a certa.

### Investigado — sinal de luz ainda não aparecendo

Revisei toda a lógica de resolução do caminho OLT → DIO → cabo adicionada
na v0.40.0, linha por linha, e não encontrei erro no código em si. Para
continuar a investigação, preciso de uma confirmação depois do apply:

1. A OLT que você ligou aparece na lista "OLT de origem", com o texto
   "· rack NOME_DO_RACK"?
   - **Se não aparecer**: o problema está na busca do cabo no servidor
     (a ligação cordão+fusão não está sendo encontrada corretamente).
   - **Se aparecer, mas a luz não acender no mapa** ao selecioná-la: o
     problema está no desenho da animação, não na busca.

São causas bem diferentes — essa resposta decide onde procurar em
seguida.

## Atualização

Execute `apply` no servidor. Não há migração nesta versão.
