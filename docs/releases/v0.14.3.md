# AFService Map v0.14.3

Esta versão adiciona pesquisa integrada ao editor e melhora as opções de mapa-base.

## Destaques

- Pesquisa por endereço brasileiro com lista de resultados.
- Pesquisa separada dentro do projeto selecionado.
- Localização de CTO, CEO, OLT, DIO, postes e cabos por nome, código ou tipo.
- Enquadramento automático de equipamentos e traçados.
- Botão de localização por GPS.
- Satélite Esri híbrido com nomes e referências viárias.
- Satélite limpo e mapa de ruas continuam disponíveis.
- Sobrezoom visual habilitado até o nível 23.

## HERE

A camada HERE não foi ativada sem credencial porque a Raster Tile API exige uma chave de aplicativo. A estrutura atual permite adicioná-la futuramente por configuração protegida.

## Atualização

Execute no servidor como usuário normal:

```bash
apply
```

Depois recarregue o navegador com `Ctrl+F5`.
