# AFService Map v0.25.0

Esta versão transforma racks e torres em estruturas técnicas configuráveis.

## Principais mudanças

- editor de estrutura em tela cheia;
- placas de OLT cadastradas individualmente por slot e quantidade de PONs;
- DIOs com capacidades padronizadas;
- switches, APs e rádios com portas RJ45, SFP, SFP+ e wireless;
- ligações internas com bloqueio de reutilização de porta;
- usuários de empresa classificados como manuais ou vinculados a ERP;
- limpeza controlada dos dados importados sem remover empresa, usuário ou token.

## Limpeza de teste da Nic Fibra

Primeiro confira o que será removido:

```bash
docker compose exec web python manage.py reset_company_imported_data \
  --company-slug nic-fibra-telecom --dry-run
```

Depois execute com confirmação:

```bash
docker compose exec web python manage.py reset_company_imported_data \
  --company-slug nic-fibra-telecom --confirm nic-fibra-telecom
```

O comando preserva a empresa, os usuários, os acessos e a configuração/token do
ERP. São removidos pontos de acesso IXC, clientes, contratos, logins, vínculos
de fibra/ONU, execuções anteriores e estrutura importada.
