# MAPA v0.75.3 — Interações do Canvas técnico

Entrega destinada ao PR #68, construída após o trabalho reservado para o PR #67.

## Principais mudanças

- seleção simples dos cards e edição somente pelo lápis;
- conectores nos lados físicos das portas;
- modos de ligação e edição com conclusão explícita;
- DROP externo e notas técnicas reposicionáveis;
- pan com botão central e tela cheia nativa;
- inventário compacto, ficha técnica corrigida e matriz somente para relatório;
- exportação PNG e PDF do Canvas com as ligações.

Não há migration nesta versão.
