# MAP v0.75.37

Atualização única para o fluxo óptico de campo e o Rack:

- CEO/CDO exibem cada cabo como coluna vertical, com uma fibra por linha.
- O painel óptico separa fusões cabo a cabo das ligações de splitter.
- No Rack, cada cabo passa a usar um ponto agregado para vínculo com o DIO.
- O DIO abre uma matriz própria com seleção fibra → porta e auto fusão sequencial.
- A OLT usa face compacta por slots e portas numéricas, sem repetir “PON”.
- Sem migrations; os cabos vinculados ao DIO são persistidos no metadata do equipamento.
