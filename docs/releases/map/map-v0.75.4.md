# MAP v0.75.4

Correções de operação do editor técnico de torre/rack.

## Entregas

- acordeão estável no inventário da estrutura;
- fibras livres e ocupadas identificadas no mesmo seletor;
- remoção segura de ligações já existentes;
- DIO com porta traseira para cabo e porta frontal para cordão;
- notas editáveis e menu contextual extensível;
- exportação PNG/PDF sem canvas contaminado;
- menu de contexto único no mapa;
- remoção do comando de tela cheia.

## Compatibilidade

- plataforma: v0.80.0;
- banco de dados: sem migration;
- cache estático: `tower-r9`.
