# AFService Map v0.28.0

Esta versão dá autonomia às empresas para montar sua própria equipe, sem
precisar do suporte da plataforma para cada novo acesso.

## Principais mudanças

- nova página **Minha equipe** (`/painel/equipe/`), reunindo quem tem acesso
  à empresa;
- o usuário principal (EDIT) cadastra um novo membro definindo nome, usuário
  e senha na hora, e escolhendo se o papel é VIEW (só visualizar) ou EDIT
  (visualizar e editar);
- o principal pode ativar/desativar o acesso de qualquer membro da equipe e
  trocar o papel dele a qualquer momento;
- atalho "Minha equipe" no dashboard e em "Minha administração".

## Limites intencionais desta primeira versão

- só é possível criar usuários novos (não é possível "importar" um login que
  já existe em outra empresa);
- não há convite por e-mail — o principal entrega usuário e senha
  diretamente para a pessoa;
- um membro não consegue se autodesativar nem mudar seu próprio papel;
- o usuário criado nunca acessa o Django Admin nem outras empresas.

## Atualização

Execute `apply` no servidor. Não há migração de banco nesta versão.
