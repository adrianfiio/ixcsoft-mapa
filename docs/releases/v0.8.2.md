# IXCSoft Mapa v0.8.2

## Correções do deploy automatizado

Esta versão corrige os problemas encontrados no primeiro uso do comando
`apply` no Debian de produção.

### Corrigido

- execução permitida em servidores administrados diretamente como `root`;
- preservação dos containers existentes de PostgreSQL e Redis;
- remoção do volume que ocultava os arquivos estáticos coletados;
- CSS do dashboard servido pelo WhiteNoise;
- versão da aplicação derivada automaticamente da tag publicada.

### Aplicação

Atualize o script uma vez e execute o deploy:

```bash
cd /opt/ixcsoft-mapa
git pull origin main
apply
```
