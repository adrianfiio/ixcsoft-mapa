# AFService Map v0.32.0

Ajustes no editor de mapa focados no cadastro de estrutura interna de rack
(OLT/DIO) e na fusão de cabos.

## Principais mudanças

- **Fusão direta de cabo no DIO**: até aqui, ligar um cabo externo (que
  chega no rack) a uma porta do DIO só era possível criando uma ligação
  completa PON da OLT ↔ porta do DIO. Agora a porta de origem é opcional —
  deixe em branco para fazer uma fusão direta do cabo numa porta do DIO,
  sem precisar de uma OLT do outro lado.
- O card de cada porta no diagrama de estrutura mostra o nome do cabo
  vinculado, quando houver, em vez de só um genérico "· ligada".
- Cadastro de **DIO**: só pede Nome, Fabricante e Quantidade de portas.
- Cadastro de **OLT**: modo Manual pede só Nome e Fabricante; modo SNMP
  soma IP de gerência e Community. Modelo e Número de série saíram desses
  dois formulários (continuam disponíveis para switch/AP/PTP na torre).
- Empresas **projetistas** (sem ERP, sem clientes) deixam de ver as camadas
  "Clientes online"/"Clientes offline" e o agrupamento de PPPoE no mapa.
- O diagrama de fusões da CTO/CEO, antes chamado "Unifilar", passa a se
  chamar **Fusões** — no botão do popup e no título do diálogo.

## Atualização

Execute `apply` no servidor. A migração torna a porta de origem opcional
numa ligação interna — não afeta ligações já existentes.
