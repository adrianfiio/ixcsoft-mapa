# IXCSoft Mapa v0.8.0

## Dashboard operacional

Esta versão restaura a página inicial como central de operações e mantém o
mapa geográfico em uma rota dedicada.

### Destaques

- Dashboard alimentado por dados reais do banco
- Indicadores de acessos online, offline e sem estado
- Resumo de clientes, OLTs, ONUs, CTOs e elementos de rede
- Alertas operacionais recentes
- Estado da última sincronização com o IXCSoft
- Navegação responsiva para os módulos principais
- Mapa operacional movido para `/mapa/`

### Atualização

Depois de atualizar o código, recrie os serviços da aplicação para carregar os
arquivos estáticos e a nova versão:

```bash
docker compose pull
docker compose up --build -d
```

Esta versão não adiciona migrations de banco de dados.
