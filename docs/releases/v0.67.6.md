# AFService Map v0.67.6

Backup/ponto de rollback desta rodada: tag `v0.67.5`.

Fecha a pendência deixada pela v0.67.5: `requirements.txt` estava sendo
editado direto no servidor pra adicionar `influxdb-client` (dependência
do projeto de monitoramento), e por ser um arquivo já rastreado pelo
Git, `.gitignore` não resolvia — continuava bloqueando o `apply`.

## Adicionado

- **`influxdb-client>=1.44,<2` em `requirements.txt`**, seguindo o mesmo
  padrão de faixa de versão já usado nas outras dependências do projeto.

## Atualização

Execute `apply` no servidor — como o pacote muda, a imagem Docker
reconstrói (`docker compose up --build`, já parte do próprio `apply`)
e instala o `influxdb-client` dentro do container. Sem migration nesta
versão.

Antes de rodar `apply`, confirme que `requirements.txt` no servidor não
tem mais nenhuma alteração pendente (a linha `influxdb-client` sem versão
que estava lá vai ser substituída pela versão do repositório ao dar
`git pull`); se `git status` ainda reclamar dele, rode `git diff
requirements.txt` de novo antes de atualizar.
