# AFService Map v0.12.4

## Correção

- Corrigidos os blocos “Map data not yet available” no zoom máximo.
- O satélite usa imagens nativas até o nível 19 e faz sobrezoom até o nível 22.
- O mapa de ruas utiliza o mesmo comportamento para manter o zoom consistente.

## Google Maps

O projeto está preparado para receber uma integração oficial depois que uma chave
do Google Maps Platform com faturamento e restrição de domínio estiver disponível.
Tiles não oficiais do Google não são utilizados.
