# AFService Map v0.57.0

Backup/ponto de rollback desta rodada: tag `v0.56.0` no GitHub.

Ajustes de navegação e do editor de dashboard, a partir do teste feito na
v0.55.0 (usuário "Lauro GAY" editando o próprio dashboard da LC-PROJETOS).

## Principais mudanças

### Adicionado

- **Menu lateral retrátil.** O botão ☰ no topo, que antes só fazia algo no
  celular, agora também recolhe/expande a barra lateral no desktop — mais
  espaço de tela quando quiser. Funciona para qualquer usuário (empresa ou
  superusuário) e o estado fica salvo no navegador, então continua
  recolhido (ou expandido) ao navegar entre páginas.
- **"Visão da plataforma" em tela cheia para o superusuário.** Já que essa
  página é o "dashboard" dele desde o redirect da v0.55.0, e ele já tem o
  Django admin (`/admin/`) pra qualquer outra necessidade administrativa,
  a barra lateral não aparece mais nessa tela — fica só o conteúdo, o
  botão "Editar este painel" e um novo botão "Abrir mapa" (repondo o
  acesso ao mapa que a barra lateral escondida deixaria de oferecer).

### Corrigido

- **Dashboard do projetista com só uma coluna.** `dashboard_designer.html`
  colocava "Dados da empresa" e "Atalhos" um embaixo do outro numa coluna
  só — sem chance de ficarem lado a lado — diferente do dashboard de
  provedor, que já tinha 2 colunas desde sempre. Agora o projetista também
  tem 2 colunas, cada card na sua.
- **Editor de dashboard, arrastar preso na tela.** No teste, um card
  ("Dados da empresa") ficou visualmente "fantasma" sobreposto a outro
  depois de arrastar — o SortableJS usa por padrão o drag nativo do
  navegador (HTML5 Drag and Drop), que em alguns casos não limpa
  corretamente o placeholder ("ghost") do item arrastado ao soltar. Ligado
  o modo `forceFallback` (arrastar emulado por mouse/touch, mais
  confiável), evitando essa falha.

### Sobre a divisão de trabalho no pacote do mapa

A partir de agora, pacotes que o ChatGPT preparar pra área do mapa/KMZ
(`apps/network_map/`, `map-editor.js`, importação KMZ) são só recebidos,
viram um backup e são publicados — sem uma revisão de código profunda
daqui, já que ele acompanha o repositório direto no GitHub e é quem cuida
dessa área agora. A v0.56.0 teve uma revisão a fundo excepcionalmente (e
valeu a pena — achou 3 problemas reais), mas isso não vai se repetir toda
vez; o foco deste lado passa a ser dashboard, whitelabel e o resto do
projeto.

## Limitação conhecida

Ainda não dá pra arrastar um widget de uma coluna/seção pra outra (só
reordenar dentro da mesma seção, ou esconder/mostrar) — isso porque a
ordem salva hoje não registra EM QUAL seção cada widget deve ficar, só a
posição relativa. Mover teria que voltar pra seção errada ao recarregar a
página. Dá pra construir isso direito se fizer falta — é um passo maior
(mudar como o layout é salvo), não entrou nesta versão.
