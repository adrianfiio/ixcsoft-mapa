# AFService Map v0.13.1

## Google Map Tiles pelo servidor

- Sessão Satellite 2D criada pelo backend.
- Blocos de satélite encaminhados pelo servidor AFService Map.
- O Google passa a enxergar o IP público do servidor Debian.
- A chave deixa de ser enviada ao navegador.
- Compatível com chave restrita ao IP do servidor.

## Atualização

Execute `apply` e recarregue o mapa com `Ctrl + F5`.
