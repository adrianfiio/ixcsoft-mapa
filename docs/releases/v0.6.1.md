# IXCSoft Mapa v0.6.1

Release de compatibilidade com EasyPanel.

## Alterações

- Adicionada a variável `WEB_URL` para centralizar a URL pública.
- Compatibilidade com `WEB_URL=https://$(PRIMARY_DOMAIN)` do EasyPanel.
- `ALLOWED_HOSTS`, CSRF e CORS passam a ser derivados de `WEB_URL` quando não informados manualmente.
- Criado `.env.example` completo para o EasyPanel.
- Versão padrão da API atualizada para `0.6.1`.
- Adicionada opção `DJANGO_SECURE_SSL_REDIRECT`.

## Configuração mínima

```env
WEB_URL=https://$(PRIMARY_DOMAIN)
DJANGO_DEBUG=false
DJANGO_SECRET_KEY=<chave-forte>
POSTGRES_HOST=postgres
POSTGRES_PORT=5432
POSTGRES_DB=ixcsoft_mapa
POSTGRES_USER=ixcsoft
POSTGRES_PASSWORD=<senha>
REDIS_URL=redis://redis:6379/0
APP_VERSION=0.6.1
```

## Deploy

Após atualizar a branch `main`, use **Implantar** no EasyPanel para reconstruir a imagem.
