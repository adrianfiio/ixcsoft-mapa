# AFService Map v0.22.0

Esta versão simplifica os modos do mapa e separa a atualização operacional PPPoE da importação completa do ERP.

## Destaques

- Visualização realmente somente leitura.
- Um único modo para editar e desenhar.
- Busca aberta somente pela lupa.
- PPPoE atualizado a cada cinco minutos.
- Sincronização completa respeitando o intervalo configurado.
- ONUs contabilizadas somente quando vinculadas a um cliente.
- Cabos do IXC deixam de ser importados sem um traçado confiável.

## Atualização

Execute `apply` no servidor. A migração remove apenas os cabos automáticos pendentes e sem geometria; cabos desenhados manualmente são preservados.
