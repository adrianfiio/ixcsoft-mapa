# AFService Map v0.9.1

Esta versão transforma os elementos desenhados em uma estrutura óptica conectável e editável.

## Principais mudanças

- Postes, CTOs, CEOs e cabos podem ser editados nos próprios pop-ups do mapa.
- Cabos podem receber origem e destino dentro do projeto.
- As pontas do traçado encaixam nos elementos conectados e acompanham sua movimentação.
- Ao criar uma CTO, o formulário solicita capacidade, proporção do splitter e quantidade de portas.
- O sistema cria e persiste as portas de atendimento.
- Cada CTO possui uma visualização unifilar com entrada, splitter e estado das saídas.

## Atualização

No servidor, como o usuário normal autorizado a usar Docker:

```bash
apply
```

O comando aplica também a nova migração de banco de dados.
