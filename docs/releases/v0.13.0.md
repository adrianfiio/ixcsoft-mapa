# AFService Map v0.13.0

## Google Satélite configurável

- Nova configuração do mapa-base no Django Admin.
- Chave da Google Map Tiles API armazenada criptografada.
- Uso exclusivo dos blocos Google Satellite 2D.
- Google Satélite disponível no seletor de camadas.
- Camada padrão configurável.
- Fallback automático para o satélite alternativo.

## Como configurar

1. Atualize o servidor com `apply`.
2. Acesse **Administração → Configuração do mapa-base**.
3. Crie a configuração **Mapa principal**.
4. Marque **Ativar Google Map Tiles**.
5. Cole a chave da API e escolha **Google Satélite** como camada padrão.
6. Salve e recarregue o mapa com `Ctrl + F5`.
