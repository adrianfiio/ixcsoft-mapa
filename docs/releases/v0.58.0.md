# AFService Map v0.58.0

Backup/ponto de rollback desta rodada: tag `v0.57.0` no GitHub (também
disponível como branch `backup/mapa-pre-v07-20260731`).

Handoff v0.7 do ChatGPT para o mapa/importador KMZ — desta vez só
especificação (`IXCSoft_MAPA_v0.7_Handoff.md`), sem código pronto, então
esta rodada foi implementada aqui a partir da descrição, comparando cada
item com o que já existia antes de mexer. Vários pontos do handoff já
tinham sido resolvidos nas v0.56.0/v0.57.0 desta mesma sessão (fallback de
cor de fibra, histórico em badges, primeiro clique em Fusões, zoom/
organizar/ajustar, reparo de fibras) e não entraram de novo.

## Principais mudanças

### Corrigido

- **Prévia do KMZ podia ficar "grudada" no mapa.** Fechar o assistente
  pelo X, ou trocar o projeto selecionado enquanto uma prévia estava
  desenhada, não limpava a camada temporária — agora os dois casos
  limpam, além dos pontos que já funcionavam (importação concluída,
  reiniciar análise).

### Adicionado

- **Importador mais largo, menos espaço vazio nas laterais** — modal até
  `min(96vw, 1680px)` (era 1480px), gutters reduzidos.
- **Scrollbar fina e discreta** no conteúdo do assistente, tabelas e
  listas de exceções.
- **Etapa Cabos**: cards com grid de 4 colunas (Ação · Tipo · Fibras/
  Metragem · Modelo), mesma altura entre cards de ações diferentes,
  nomes e pastas longos com clamp de 1-2 linhas e tooltip com o texto
  completo.
- **Etapa Rotas**: "Marcar todas" / "Desmarcar todas" / "Marcar somente
  rotas com linhas"; checkbox trocado por um toggle moderno arredondado.
- **Etapa Ligações**: seção "Aplicar para todos" — 2 selects (CTO no
  meio / CEO-CDO no meio) + botão, aplica a regra a todas as ligações já
  detectadas de uma vez. Os selects de padrão que já existiam continuam
  do jeito que estavam (só valem pra detecções futuras); a novidade é
  poder sobrescrever o que já foi detectado, de uma vez, sem editar linha
  por linha.
- **Sidebar do mapa mais compacta**, com scrollbar fina.
- **Trilha lateral recolhida completa**: antes só aparecia com a sidebar
  em modo de edição, e mesmo assim sem link de voltar. Agora sempre
  mostra "← Voltar para visão geral" e um ícone de olho (camada
  "Geral"), independente do modo — as ferramentas de desenho continuam
  restritas ao modo de edição.
- **Ícone de olho nas camadas** — os checkboxes de camada na sidebar
  (CTO, CEO, cabos, clientes...) mostram ⊙ visível / ⊘ oculto em vez do
  checkbox nativo do navegador. Comportamento por baixo idêntico, só a
  aparência mudou.
